窗格的位置由 Claude Code 決定，而非由 mod 決定。實際位置取決於版面和終端機的寬度。

| 位置 | 您會看到 |
| --- | --- |
| 停靠（全螢幕，≥ 110 欄） | 房間分頁、FRIENDS 卡片，以及房間訊息的對話泡泡：您的在右邊、他人的在左邊，依發送者分組，附日期標籤，並以 **new** 分隔線標示上次閱讀的位置 |
| 提示列上方（較窄時） | 房間、誰在線上、最後五則訊息和輸入框 |
| 窗格關閉時 | 一行：房間、誰在線上、未讀數、最新一則訊息和 **Open** |
| 狀態列 | 每個房間的未讀數，例如 `💬 #team 3`，勿擾模式時是 `🔕 #team 3`。內建房間會在 context 快滿時加上 `◔ 85%`、這個分支的檢查失敗時加上 `✗ CI`、專注計時器執行時加上 `🍅 18:42`，其餘情況不顯示。 |

在桌面版 App 裡，這一行會變成由小圖組成的膠囊。各房間的樣式請參閱[桌面版 App](/squad-chat/zh-tw/use/desktop/)。

## 取得停靠版面

1. 用 `/tui fullscreen` 將 Claude Code 切換為全螢幕版面。
2. 將終端機調整為至少 110 欄寬。
3. 用 `/chat` 開啟窗格。
