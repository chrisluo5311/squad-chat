在 Claude Code 桌面版 App（2.1.292 或更新版本）裡，聊天和每個房間都以 App 原生的元件繪製：小圖、圓角膠囊和 App 的按鈕，取代終端機的字元圖形。功能與指令皆與終端機版相同。

## 標頭

- 內建房間的**房間圖示**。**+** 會列出還沒有分頁的房間，點選即可加入。
- **您的聊天室**自成一行。**＋ join** 會依序詢問房間名稱與通行碼。

## 聊天

與手機相似的對話泡泡，自己的訊息在右側，成員以小標籤顯示。聊天區維持固定高度並可獨立捲動：**▲** 顯示更早的訊息，**↓ N newer** 回到最新訊息。

## 橫條（band）

窗格關閉時，提示列上方那一行會變成由小圖組成的膠囊，每項數據以一張小圖呈現，滑鼠移至其上會顯示卡片。**‹** 和 **›** 切換房間，效果和 `/chat band <room>` 一樣。各房間的呈現方式不同（此處數字僅為示意）：

## 房間

每個房間都有專為 App 設計的內容。主要差異如下：

| 房間 | 在桌面版上 |
| --- | --- |
| Usage | 花費以三個方格呈現，subagent 數量以大字顯示 |
| Git | 類似 Fork 的 commit 圖，連結可直接開啟 |
| Agents | 每個工作階段一行，執行中時顯示旋轉的圓環 |
| Pet | 會活動的向量版 Clawd，並會在輸入框旁走動 |
| Weather | 每個城市一格、一條 24 小時曲線、太陽的弧線 |
| Snippets | 程式碼區塊，附 Copy、Share 和 Delete |

各房間的截圖請參閱[內建房間](/squad-chat/zh-tw/use/built-in-rooms/)。
