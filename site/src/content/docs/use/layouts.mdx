Claude Code, rather than the mod, determines where the pane is placed, based on the layout and the width of the terminal.

| Where | What you see |
| --- | --- |
| Docked (fullscreen, ≥ 110 columns) | Room tabs, a FRIENDS card, and the room's messages as bubbles: yours on the right, theirs on the left, grouped by sender, with date labels and a **new** line where you stopped reading |
| Above the prompt (narrower) | The room, who is online, the last five messages and the input box |
| Pane closed | One line: the room, who is online, unread count, the latest message and **Open** |
| Status line | Unread counts per room, such as `💬 #team 3`, or `🔕 #team 3` during do not disturb. The built-in rooms add `◔ 85%` when the context is nearly full and `✗ CI` when this branch's checks fail and `🍅 18:42` while a focus timer runs, and nothing otherwise. |

In the desktop app, this line is rendered as a capsule of small drawings instead. See [Desktop app](/squad-chat/use/desktop/) for every room's version.

## Getting the docked layout

1. Switch Claude Code to its fullscreen layout with `/tui fullscreen`.
2. Make the terminal at least 110 columns wide.
3. Open the pane with `/chat`.
