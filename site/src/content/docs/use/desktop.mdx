In the Claude Code desktop app (2.1.292 or newer), the chat and every room are rendered with the app's native components: drawings, rounded pills and buttons, in place of the terminal's glyphs. All features and commands work the same way.

## The header

- **Room icons** for the built-in rooms. **+** lists the rooms without a tab and adds the one you select.
- **Your chats** on a separate line. **＋ join** prompts for a room's name, then its passcode.

## Chat

Message bubbles similar to a phone's, with yours on the right and other members shown as chips. The chat keeps a fixed height and scrolls independently: **▲** shows older messages, **↓ N newer** returns to the latest messages.

## The band

With the pane closed, the line above the prompt is a capsule of small drawings, one per figure, with a card shown on hover. **‹** and **›** switch rooms, as `/chat band <room>` does. Each room renders its own (the figures shown are illustrative):

## Rooms

Each room has a layout designed for the app. Notable differences:

| Room | On the desktop |
| --- | --- |
| Usage | Spend as three tiles, subagent counts set large |
| Git | A commit graph like Fork's, links that open |
| Agents | Each session on one line, a ring spinning while it works |
| Pet | An animated vector Clawd that also walks beside the input box |
| Weather | A tile per city, a line for 24 hours, the sun's arc |
| Snippets | Code blocks with Copy, Share and Delete |

See [Built-in rooms](/squad-chat/use/built-in-rooms/) for a screenshot of each.
